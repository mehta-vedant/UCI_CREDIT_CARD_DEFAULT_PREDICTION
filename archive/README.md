# Archived project material

This folder keeps historical project material that is no longer part of the active credit-risk application. Nothing here is loaded by the current Flask app or by `src/credit_risk`.

- `legacy-experiments/`: previous notebooks, copied projects, and fraud-oriented experiments.
- `legacy-python-pipeline/`: the earlier training and prediction implementation.
- `legacy-artifacts/`: artifacts produced by the earlier pipeline.
- `legacy-next-ui/`: the former Next.js frontend and deployment configuration.
- `legacy-docs/`: prior documentation and generated explanations.
- `legacy-notebooks/` and `legacy-training-logs/`: notebooks, checkpoints, and old training output.

The active code lives at the repository root under `src/credit_risk`, `templates`, `tests`, `data`, `models`, and `reports`.
