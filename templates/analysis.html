Then: compare feature importance across models

The project compares Logistic Regression, Random Forest, and CatBoost. Each model has a different internal language, so feature-importance values are not directly comparable across the three panels. The chart answers “which inputs mattered most to this fitted model?” It does not answer “what caused this client to default?”

Logistic Regression

Its coefficient sign tells direction and absolute standardised coefficient tells relative strength after scaling. It is a linear view: interactions must be explicitly represented by features.

Random Forest

Its split importance reflects how useful a feature was across many trees. It captures nonlinear splits and interactions, but can favour features with many possible split points.

CatBoost

Its split importance comes from boosted trees. The project also produces a CatBoost SHAP summary, which gives a more detailed global contribution view for the selected model.

Interpretation rule: correlation, coefficient magnitude, split importance, and SHAP values are different tools. None makes a causal or fairness claim. Use them with evaluation metrics, domain expertise, and human review.
Selection and final evaluation

Why CatBoost is served by the website

All candidates use the same feature/preprocessing path, three-fold stratified cross-validation, and ROC-AUC selection. CatBoost had the highest mean training-fold ROC-AUC, then the project selected a 24.5% review threshold using validation F1 before testing once on the final holdout.

Keep the claim honest

What this project does and does not establish

The model is an educational early-warning and review-prioritisation prototype. It uses historical academic data from one population and period. It does not establish fairness, legal compliance, causal effects, live calibration, or suitability for autonomous lending decisions.

For a complete beginner explanation, use the learning guide. For hands-on EDA, open notebooks/01_eda_and_feature_engineering.ipynb.
