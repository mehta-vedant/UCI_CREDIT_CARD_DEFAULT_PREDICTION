Project in one paragraph

Flask credit-risk application for next-month payment default, trained on UCI's 30,000-row historical Taiwan credit-card dataset. It is not fraud detection. The full sklearn feature/preprocessing pipeline and selected CatBoost model are saved together and served by the website/API.

Pipeline

CSV→stratified split→past-only features→impute / encode / scale→CV model comparison→validation threshold→test / joblib / Flask

Models and choice

Compared logistic regression, random forest, CatBoost. CatBoost was selected on highest cross-validated ROC-AUC (0.7876). The selected settings are depth 6, 150 iterations, learning rate 0.03, L2 regularisation 3.

Formulas

precision = TP/(TP+FP) · recall = TP/(TP+FN) · F1 = 2PR/(P+R) · specificity = TN/(TN+FP) · balanced accuracy = (recall+specificity)/2

Interview talking points

  • Accuracy alone fails with 22.12% positives.
  • 0.245 maximises validation F1; it is not a universal banking policy.
  • Pipeline fitting inside CV avoids preprocessing leakage.
  • Feature engineering uses only historical months.
  • Dataset is academic and historical, so production needs monitoring, fairness review, calibration checks, security, and governance.
