3. Machine learning from zero

The minimum vocabulary needed to read the rest of the project without pretending you already know it.

AI, machine learning, and this project

Artificial intelligence is a broad name for computers doing tasks associated with human judgement. Machine learning is one branch: instead of writing every rule, we give an algorithm examples and let it fit a pattern. Supervised learning means each training example has an input and a known answer. This project is supervised learning because old client records include the later default label.

Unsupervised learning looks for structure without labels, such as grouping similar clients. Reinforcement learning learns through rewards after actions, such as an agent learning a game. Neither is the approach used here.

Classification versus regression

Regression predicts a number such as next month's balance. Classification predicts a category. Here the category has two possible values, default or no default, so it is binary classification. The model still produces a number first: a probability from 0 to 1. A threshold turns that probability into a yes/no review flag.

How a model learns

features: history and amounts+known label: default?→algorithm adjusts internal settings→trained model

During training, the algorithm makes a probability estimate for a known historical row. A loss function measures how wrong and how overconfident that estimate was. Optimisation adjusts internal parameters to reduce average loss. Gradient descent is a common method for this adjustment: it calculates a direction that should reduce loss and takes many small steps. CatBoost and random forest use tree-building rather than plain gradient descent in the same form, but they still optimise an objective while fitting.

Parameters and hyperparameters

A parameter is learned from data, such as the coefficients in logistic regression or the tree splits in a forest. A hyperparameter is chosen before fitting, such as number of trees, tree depth, or learning rate. The training script searches a small set of hyperparameters using cross-validation.

Training, validation, and test

Imagine studying for an exam. Training data is the worked practice you learn from. Validation data is a mock exam used to choose settings and the decision threshold. Test data is the final sealed exam used once for an honest report.

Generalisation, overfitting, and leakage

A model generalises when it works on unseen clients, not only rows it has seen. Underfitting means it is too simple to learn useful structure. Overfitting means it memorises quirks of training data and loses performance on new data. Data leakage is worse: information from validation/test or from the future slips into training, making results look unrealistically good. The fitted pipeline and three-way split are designed to prevent that.

What is cross-validation?

It repeatedly divides the training partition into folds. A model trains on some folds and scores the held-out fold, then rotates. The script uses stratified folds so each fold keeps roughly the same default proportion.

What is the difference between an algorithm and a model?

CatBoost is an algorithm, a recipe for learning. The saved CatBoost pipeline after it sees this project's training data is a trained model.
