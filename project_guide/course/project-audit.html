Verified final results

Selected model: CatBoost. Test ROC-AUC 0.7805; average precision 0.5582; accuracy 0.7757; precision 0.4941; recall 0.5998; F1 0.5419; balanced accuracy 0.7127; log loss 0.4298. Confusion matrix: TN 3,858, FP 815, FN 531, TP 796.

Technical concerns

  • The dataset is historical and academic, with no time column available for a temporal holdout.
  • The chosen F1 threshold is not an operational cost policy.
  • Individual feature effects and statistical associations are not causal explanations.
  • A public application needs additional security and governance before any real credit use.

Audit status: documentation reflects the active, refactored implementation and labels absent capabilities as improvements rather than achievements.
