ACTIVE PROJECT GUIDE

What you are looking at

This project estimates whether a credit-card client will miss the next month's payment. It is a credit default prediction project, not a fraud detector. Fraud asks whether a transaction is unauthorized. Default prediction asks whether a client is likely to fail to repay. Mixing those up in an interview is an easy mistake, so keep the distinction clear from the beginning.

The live application takes 23 client fields, sends them through one saved preprocessing-and-model pipeline, and returns a probability plus a review recommendation. The model was trained on 30,000 historical records and evaluated once on an untouched 6,000-row test set.
