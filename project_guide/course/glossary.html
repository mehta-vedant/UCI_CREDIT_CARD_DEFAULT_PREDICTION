Glossary

Plain-English definitions for the vocabulary used in this project.

A–F

Accuracy
Share of all predictions that are correct.
Average precision
Summary of a precision-recall curve across thresholds.
Calibration
Whether predicted probabilities match observed rates.
CatBoost
A gradient-boosted decision-tree algorithm selected by this project.
Cross-validation
Repeated training/held-out scoring within the training partition.
Data leakage
Information unavailable at prediction time entering training or evaluation.
Default
Failure to meet a credit repayment obligation; not necessarily fraud.
Feature
An input value supplied to a model.
F1 score
Harmonic mean of precision and recall.
False negative / positive
A missed default / an unnecessary default flag.

G–P

Generalisation
Performance on unseen examples.
GridSearchCV
Scikit-learn search over named hyperparameter combinations with cross-validation.
Hyperparameter
Configuration selected before a model is fitted, such as tree depth.
Imputer
A transformation that fills missing values by a rule.
Inference
Using a fitted model to make a prediction.
Log loss
A probability-sensitive error measure that punishes confident wrong estimates.
Model
An algorithm after it has learned from training data.
One-hot encoding
Representing a category using yes/no columns.
Overfitting
Memorising training quirks rather than learning reusable patterns.
Precision
Of cases flagged positive, share that were truly positive.

R–T

Random forest
Ensemble of many decision trees.
Recall
Of actual defaults, share caught by the model.
ROC-AUC
Threshold-independent ranking score based on the ROC curve.
Scaling
Changing numeric magnitudes, such as standardisation to mean 0/spread 1.
SHAP
Method for attributing a model prediction relative to a baseline.
Stratification
Keeping target proportions similar across partitions/folds.
Target / label
The answer the model is trained to predict.
Threshold
Probability cutoff that turns a score into a yes/no action.
True positive / negative
A correct positive flag / correct negative decision.
