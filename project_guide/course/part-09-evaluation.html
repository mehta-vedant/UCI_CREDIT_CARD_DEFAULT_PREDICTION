ROC-AUC and average precision

The ROC curve moves a threshold from high to low. Its vertical axis is true-positive rate (recall), and its horizontal axis is false-positive rate: FP / (FP + TN). 0.5 is random ranking; 1.0 is perfect ranking. ROC-AUC 0.7805 means a randomly selected default is generally ranked above a randomly selected non-default about 78% of the time.

The precision-recall curve focuses on the default class. With only 22.12% positives, it is often more revealing than ROC alone because many true negatives can make false-positive rate appear small. Neither curve selects a business threshold by itself.

Probability quality and calibration

A calibrated 0.30 prediction means cases receiving about 0.30 should default about 30% of the time over a suitable group. ROC-AUC measures ranking; calibration measures whether probability values mean what they say. Reports include a calibration chart, but the project does not add a separate calibration model such as Platt scaling or isotonic regression.

SHAP explainability

GLOBAL EXPLANATION

src.credit_risk.explain uses SHAP on a reproducible 500-row source sample to make a global summary plot. SHAP values estimate how features push predictions relative to a baseline. They help inspect patterns, but do not prove a feature causes default. The website does not currently show individual SHAP explanations.

What is MCC?

Matthews correlation coefficient uses all four confusion-matrix cells and ranges from −1 to 1. It is useful for imbalance, but the active report does not calculate it.
