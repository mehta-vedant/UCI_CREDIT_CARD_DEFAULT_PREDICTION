13. EDA, feature importance, and model explanation

Learn the difference between a pattern in the raw data and a feature used by a trained model.

ACTIVE TRAINING REPORTS

Four questions that sound similar but are not

ToolQuestion it answersWhat it cannot prove
EDA distribution“What values appear in the dataset, and how often?”Why a value occurs or whether it causes default.
Correlation / heatmap“Which raw numeric values move together in a linear way?”Cause, fairness, or nonlinear model behaviour.
Model feature importance“Which transformed inputs did this fitted model use most?”That the feature causes the outcome.
SHAP“How did features push this model's estimates relative to its baseline?”A legal, ethical, or causal explanation.

EDA: the raw-data view

A correlation heatmap is a grid of pairwise Pearson correlations. The value ranges from −1 to 1. Values near 1 move together linearly; values near −1 move in opposite directions; values near 0 have little linear association. In this project, the heatmap includes the target, credit limit, age, repayment statuses, and recent bill/payment amounts. It helps you see that repayment-status fields are related to each other and to default. It does not say that a late-payment code alone decides the outcome.

Use EDA before modelling to check data quality, class imbalance, distributions, and plausible signals. Use it to form questions, not to write rules for people.

Feature importance for all implemented models

The training script fits the best cross-validation configuration for all three candidates on the training partition, then creates one panel per model. Read each panel separately because the numbers use different definitions.

ModelImportance methodHow to read it
Logistic RegressionAbsolute standardised coefficientAfter scaling, larger absolute coefficients mean a stronger linear push in either direction. The sign, inspected separately, tells direction.
Random ForestBuilt-in tree split importanceHigher values mean the feature was more useful for reducing tree impurity across forest splits. Continuous variables can receive a bias because they offer many split points.
CatBoostBuilt-in boosted-tree split importanceHigher values mean the feature was more useful to the boosted tree ensemble. It captures nonlinear rules and interactions.

The feature-importance chart is saved at reports/model_feature_importance.png and copied to the public project page. It is generated during python -m src.credit_risk.training --seed 42, so it reflects the same candidate run as the model comparison.

Why SHAP remains useful for CatBoost

CatBoost is the selected model. SHAP takes the fitted model and estimates how each transformed feature changes a prediction relative to an average baseline. The project generates a global SHAP summary from a reproducible 500-row sample. A point farther right or left shows a larger positive or negative contribution for that sample row. It is more detailed than simple split importance, but it is only implemented for the selected CatBoost pipeline.

NOT IMPLEMENTED

Per-client SHAP explanations, permutation importance on an untouched evaluation set, partial-dependence plots, fairness subgroup analysis, and causal inference are not active features. They are valid next steps, but should not be claimed as current project outputs.

How to explain this in an interview

“What did EDA tell you?”

“The supplied CSV had no missing cells or duplicate rows/IDs. Defaults were the minority class at 22.12%, so accuracy alone was unsafe. Recent repayment-status fields had the strongest raw association with default, which supported creating history summaries, but I treated it as association rather than causation.”

“What is the difference between correlation and model importance?”

“Correlation is a one-variable linear summary of raw data. Model importance describes how a fitted algorithm used transformed features along with other features. The model can capture nonlinear interactions that correlation misses. Neither proves cause.”

“Why do different models show different important features?”

“They learn different functions. Logistic regression learns a weighted linear combination. A forest and CatBoost use conditional tree splits and interactions. I compare rankings within the same method rather than claiming their importance scales are identical.”
