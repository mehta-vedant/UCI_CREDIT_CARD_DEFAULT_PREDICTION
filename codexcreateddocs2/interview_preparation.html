Interview preparation

Natural scripts, 100 project-specific questions, weaknesses and mock practice. All claims are constrained by active root evidence.

30-second script

I built a binary classifier for next-month credit-card payment default using UCI client credit history. The active pipeline engineers 42 features, compares six models and saves CatBoost. Its verified 6,000-row holdout ROC-AUC is 0.784934; I discuss recall as well as accuracy because the data is imbalanced.

90-second script

This is default prediction, not fraud. The data has 30,000 2005 Taiwan client records and 22.12% defaults. I drop ID, repair anomalous category codes, add utilisation/payment-ratio/delay/trend features, then impute, encode and scale. The trainer tunes six models; saved CatBoost has ROC-AUC 0.784934, accuracy 0.820167, precision 0.664789 and recall 0.359482. I openly state it is educational: test helped select the model, threshold/calibration/fairness/monitoring are not implemented.

3–5 minute presentation flow

  1. Problem: default not fraud.
  2. Motivation: prioritisation, never automatic decision.
  3. Data and EDA facts.
  4. Features/preprocessing.
  5. Imbalance.
  6. Models/training.
  7. Metrics/matrix.
  8. Limitations/future work.
