What this means

AI is broad; machine learning learns patterns from examples. Supervised learning has answers, as here. Unsupervised learning finds structure without labels; reinforcement learning learns actions from rewards; neither is implemented. Regression predicts a numeric quantity; classification chooses a category. An algorithm is the recipe; a trained model is that recipe after fitting learned parameters. Hyperparameters like depth are selected before/during search.

What happens while a model learns

At first, a model makes poor guesses. Training gives it a row of features and the known label. A loss function puts a number on how wrong the prediction was. Optimisation changes the model's internal parameters so that similar mistakes become less common on the training data. Different algorithms make those changes differently. Logistic regression learns weights. A decision-tree model learns questions that split groups of rows. CatBoost builds many small trees one after another.

Training performance alone is not persuasive. A student can memorise a practice sheet and still fail a new exam. That is why the repository makes a train/test split. The test rows should act like the new exam. This project gets one important part right: the preprocessor is fitted on train rows and applied to test rows. It also has a later design issue: model choice compares test scores. Chapter 10 explains why that makes the final score less independent.

Validation and cross-validation

Validation is a rehearsal for the final test. In cross-validation, the training data is divided into folds. The system trains on some folds and validates on the remaining fold, rotating the held-out fold. A score averaged across rotations is less dependent on one lucky partition. The active trainer uses two folds. More folds can give a steadier estimate, though they cost more computation.

Data leakage in plain English

Leakage is an unfair hint from the answer sheet. A simple example: calculate the average of the entire dataset before the split, then use it to scale training rows. The training process has indirectly seen the test distribution. More serious examples include a column recorded after default, or a future payment. Leakage can produce impressive-looking scores that disappear in real use.
