If rebuilding in 2026

  1. Start with current permitted data and a data contract.
  2. Put transforms/resampling/estimator in one versioned pipeline and stratified CV.
  3. Reserve test data and choose threshold/calibration against documented harms and review capacity.
  4. Add schema, artifact, integration/security tests.
  5. Add fairness, monitoring, drift alerts, human review and appeals.
