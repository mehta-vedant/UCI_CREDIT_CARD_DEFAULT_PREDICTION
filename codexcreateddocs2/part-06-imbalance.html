Part 6

Class imbalance

A high accuracy can still fail to catch the people of interest.

IMPLEMENTEDactive root evidence
CONCEPTUALclearly labelled context
LIMITATIONnever fabricated

What this means

Defaults are the minority (22.12%). An all-no-default classifier gets 77.88% accuracy and zero default recall. Oversampling copies minority rows; undersampling discards majority rows; SMOTE synthesises minority neighbours; ADASYN focuses harder areas; class weights penalise minority errors more; threshold adjustment converts probability at a non-.5 cutoff. All have trade-offs.

Use a concrete example

Imagine 100 records with roughly this dataset's balance: 78 people do not default and 22 do. A lazy model that answers "no default" for all 100 is right 78 times. The accuracy looks respectable. It is useless for finding the 22 people in the class we are trying to identify. Recall exposes this problem because recall asks: out of all actual defaults, how many did we catch?

There is no universally correct balance technique. If a team lowers the threshold, it flags more potential defaults. That often increases recall, but also sends more people to review who would not default. If a team adds class weights, it tells the learning algorithm that a missed default counts more during fitting. If it uses SMOTE, it creates artificial training points between similar positive examples. Each choice changes the trade-off and needs to be measured on data that was not resampled.

What your current code chose

The active trainer did not use SMOTE, ADASYN, random sampling, or class weights. That is a valid baseline choice, but it has a visible consequence at the default cutoff: the verified model catches 472 of 1,313 defaults in the saved test split. It does not mean resampling would definitely be better. It means that the repository does not contain the experiment needed to support a claim either way.

When accuracy is still useful

Accuracy is not useless. It answers a real question: how often was the final hard label correct? It becomes dangerous when it is the only metric, especially when one class is more common. Read it alongside the entire confusion matrix, precision, recall, F1, ROC-AUC and, where relevant, average precision and business cost.
