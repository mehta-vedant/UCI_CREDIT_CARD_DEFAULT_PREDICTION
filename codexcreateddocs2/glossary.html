Reference

Glossary

Alphabetical project terminology.

Accuracy

Correct predictions divided by all predictions.

AUC

Area under curve; ROC-AUC measures ranking across cutoffs.

Bias

Error from overly restrictive assumptions.

Binary classification

Choosing two labels.

Calibration

Whether probabilities match observed frequencies.

CatBoost

Saved gradient-boosted classifier.

Class imbalance

Unequal class counts.

ColumnTransformer

Sklearn router for column groups.

Confusion matrix

TP/TN/FP/FN count table.

Cross-validation

Rotated train/validation splits.

Data leakage

Evaluation/future information affects fitting.

Feature

Model input variable.

F1

Harmonic mean of precision and recall.

fit

Learn statistics/parameters from data.

GridSearchCV

Search supplied hyperparameter combinations with CV.

Hyperparameter

Chosen setting such as tree depth.

Inference

Prediction from a fitted model.

Log loss

Probability-quality error.

One-hot encoding

Categories converted to indicator columns.

Overfitting

Memorising sample quirks.

Precision

Correct positives divided by predicted positives.

Recall

Correct positives divided by actual positives.

ROC curve

TPR/FPR across thresholds.

StandardScaler

Mean-center and scale by training standard deviation.

Target

Known answer predicted by supervised learning.

Threshold

Probability cutoff for hard class.
