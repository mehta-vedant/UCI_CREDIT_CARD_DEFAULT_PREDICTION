What this means

Logistic regression makes a linear weighted probability; Random Forest averages varied trees; Gradient Boosting and AdaBoost add learners sequentially; XGBoost and CatBoost are powerful boosted-tree variants. Trees can learn nonlinear interactions in tabular data; they can also overfit and importance is not causation.

Why compare several models

There is no rule that says one algorithm always wins on tabular credit data. Logistic regression gives a simple baseline. It assumes the log-odds can be represented by a weighted combination of features. A single decision tree can ask questions such as "is the recent delay at least two?" but can be unstable. Random Forest reduces that instability by averaging many varied trees. Boosting methods build trees in sequence, with later trees trying to improve earlier mistakes.

CatBoost is the winner saved in the current artifact. It is a gradient-boosting method, meaning it adds trees one at a time to reduce a loss. Each tree makes small corrections to the existing prediction. Depth controls how many levels a tree may use. Learning rate controls how strongly each new tree changes the combined score. More iterations allow more correction steps. These settings are trade-offs: bigger or deeper models may capture more detail, but can also learn noise.

Reading feature importance safely

The loaded model says PAY_0 has the largest internal importance. That is believable given the dataset and EDA, but it does not mean late payment directly causes default or that the value applies to every individual. Different importance methods can rank features differently, correlated features can share credit unpredictably, and importance says nothing about fairness. Use it as a lead for inspection, not as a customer-facing reason code.

Models absent from the code

Support vector machines, K-nearest neighbours, Naive Bayes, LightGBM and neural networks can be useful teaching comparisons. They were not candidates in the active trainer. In an interview, say what was tested, then explain how you would design a fair additional experiment instead of claiming a model was rejected.

default.payment.next.month: 1 means default, 0 no default.

An input clue such as PAY_0 or LIMIT_BAL.

Beginner — Why test data?

To estimate performance on records not used to fit.

It is historical Taiwan 2005 data, not production lending data.

Cite active root source, paired artifacts, data inspection or recomputed metrics.

ROC-AUC; active GridSearchCV uses it.

Always predicting no default yields 77.88% accuracy and zero recalls.
